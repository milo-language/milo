# std/sha256

## std/sha256

### `Sha256.bytes`

```milo
fn Sha256.bytes(input: &string): string
```

SHA-256 digest as 32 raw bytes. Use this when the digest feeds further bytes
(HMAC, key derivation); `Sha256.hash` wraps it for the common hex case.

### `Sha256.hash`

```milo
fn Sha256.hash(input: &string): string
```

SHA-256 digest as a 64-char lowercase hex string.
