# std/cache

Bounded in-memory caches: `LruCache<K, V>` evicts the least recently used entry once it holds `capacity` entries, and `TtlCache<K, V>` expires each entry a fixed time after it was put, optionally with an LRU capacity as well. Both are built on [std/collections](collections)' `OrderedMap`, and every operation is amortized O(1) except `TtlCache.purge`.

```milo
from "std/cache" import { LruCache, TtlCache }
```

## LruCache

`get`, `modify` and `put` count as a use; `peek` and `contains` do not.

```milo
from "std/cache" import { LruCache }

fn main(): i32 {
    var c = LruCache<string, i64>.new(2)
    c.put("a", 1)
    c.put("b", 2)
    print(c.get("a")!)                      // 1, and "a" is now the most recent
    c.put("c", 3)                           // evicts "b", the least recently used
    print(c.contains("b"))                  // false
    return 0
}
```

## TtlCache

Expiry is lazy: an expired entry is never served, and is dropped when a lookup meets it or `purge()` sweeps. Until then it still counts in `len` and toward the capacity. `putFor` overrides the ttl for one entry.

The clock is `epochMillis` from std/time; `setClockMs` swaps in another, which is how a test steps time without sleeping. The closure is `move`, so it reads a global rather than a captured local:

```milo
from "std/cache" import { TtlCache }
from "std/time" import { Duration }

var fakeNow: i64 = 0

fn main(): i32 {
    var c = TtlCache<string, string>.withCapacity(Duration.secs(30), 1000)
    c.setClockMs(move (): i64 => fakeNow)
    c.put("session", "alice")
    fakeNow += 10000
    print(c.get("session")!)                // alice
    fakeNow += 30000
    print(c.get("session").isNone())        // true: expired and dropped
    print(c.purge())                        // 0: nothing left to sweep
    return 0
}
```

For a value carrying `Drop`, `get` (a copy) is not available; read it in place with `modify`.

### `TtlCache`

```milo
pub struct TtlCache<K, V>
```

A cache whose entries expire a fixed time after they were put (or a per-entry time
with `putFor`), optionally also bounded to `capacity` entries with LRU eviction.

Expiry is lazy: an expired entry is never served, and is dropped when a lookup
meets it or when `purge` sweeps. Until then it still counts in `len` and toward the
capacity, so a cache that is written but rarely read should `purge` now and then.

The clock is `epochMillis` from std/time unless `setClockMs` swaps in another, which
is how a test steps time without sleeping.

Fields:

- `map: OrderedMap<K, Stamped<V>>`
- `ttlMs: i64`
- `cap: i64`: 0 means unbounded.
- `clock: move () => i64`

#### `TtlCache.getWithin`

```milo
fn TtlCache.getWithin(self: &mut TtlCache, key: &K, maxAge: &Duration): Option<V>
```

A copy of the value under `key` if it has not expired and was put less than
`maxAge` ago, marking it most recently used; None otherwise. An entry too old
for `maxAge` but not yet expired stays, untouched, for a later read with a
looser bound: put with the longest age any reader accepts (say 60 s for a
stale-if-error fallback) and read the fresh path with a shorter one (2 s).
