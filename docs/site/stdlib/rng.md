# std/rng

Seedable, reproducible pseudo-random numbers. [`std/random`](random) is a CSPRNG,
unpredictable by design and impossible to replay; this is the other half, for
simulations, procedural worlds, property tests and golden-frame renders, where the same
seed must give the same stream on every platform. The generator is SplitMix64. It is
**not** cryptographically secure.

```milo
from "std/rng" import { Rng }
```

## Example

```milo
var a = Rng.new(42)
var b = Rng.new(42)
print(a.range(1, 6) == b.range(1, 6))   // true: same seed, same stream
print(a.float() < 1.0)                  // true
```

#### `Rng.int`

```milo
fn Rng.int(self: &mut Rng, max: i64): i64
```

Uniform in [0, max). Returns 0 when max &lt;= 0 rather than trapping, so a
caller looping over an empty range degrades instead of aborting.

Modulo, not rejection sampling: the bias is 2^-64 per unit of max, which is
unmeasurable for any max a program actually passes, and rejection would
make the stream length input-dependent — which breaks replay.
