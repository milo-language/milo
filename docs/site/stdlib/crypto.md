# std/crypto

Cryptographic hashing and authenticated encryption, backed by the platform crypto library (CommonCrypto on macOS, OpenSSL on Linux).

```milo
from "std/crypto" import { Crypto }
```

For dependency-free, constant-time implementations and higher-level primitives, see the pure-Milo companions: [`std/sha256`](sha256), [`std/sha512`](sha512), [`std/sha1`](sha1), [`std/hmac`](hmac), [`std/subtle`](subtle), [`std/hkdf`](hkdf), [`std/pbkdf2`](pbkdf2), [`std/jwt`](jwt), [`std/totp`](totp), and [`std/base32`](base32).

## Example

```milo
let hash = Crypto.sha256("hello world")
// "b94d27b9934d3e08a52e52d7da7dabfac484efe37a5380ee9088f7ace2efcde9"
```

AES-GCM is authenticated encryption with a 256-bit key (`aesGcm*`) or a 128-bit key (`aesGcm128*`). Decryption with the wrong key, IV or tag is an `Err`, never silent corruption:

```milo
let out = Crypto.aesGcmEncrypt(key, iv, "secret", "")!
let plain = Crypto.aesGcmDecrypt(key, iv, out.ciphertext, out.tag, "")!
```

### `AesGcmResult`


The two outputs of an AES-GCM encryption. Keep both: decryption needs the `tag`.

Fields: `ciphertext: string`, `tag: string`.

Decrypt and authenticate with AES-256-GCM: 32-byte key, 12-byte IV, and the
16-byte `tag` from encryption. A tag that does not verify is an `Err`, never
corrupted plaintext.

Encrypt with AES-256-GCM. The key is 32 bytes and the IV is 12 bytes.

`aad` is additional authenticated data; pass "" if unused. The key and IV lengths
are preconditions (`requires`), not runtime errors.
