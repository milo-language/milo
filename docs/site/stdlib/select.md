# std/select

Wait on the first ready of many sources, like Go's `select`. Arm channel receives and
sends, fd reads and writes, or a timeout, then `wait` parks until one fires and returns
the winning arm's index. The value of a receive arm is fetched afterwards with
`ch.recv()` or `tryRecv()`, which keeps `Select` non-generic; that is also why only
single-consumer channels are supported.

On a program that never spawned a green task there is no scheduler, so a timeout arm
never fires. The helpers in [`std/timer`](timer) call `ensureTimersLive()` first.

```milo
from "std/select" import { Select }
```

#### `Select.onRead`

```milo

```

Arm on `h` becoming readable. The arm holds the descriptor number until wait()
returns, so `h` must stay alive across the wait; borrowing it here is what keeps
a caller from arming a number nothing owns.
