# Compiler Source Index

Every file in `src/`, with the purpose it states in its own opening comment. The table is
generated by `scripts/gen-src-doc.ts` and gated by `tests/srcDoc.test.ts` — **do not edit
it here.** To change an entry, change the first sentence of that file's header comment.

The pipeline those files form:

```
Source → Lexer → Parser → AST → Resolver (imports) → AST (merged) → TypeChecker
       → HIR Lowering → Codegen → LLVM IR → clang → Binary
```
